# World Happiness Report – Data Analysis

## Project Overview

This project analyzes the World Happiness Report using Microsoft Excel to explore global happiness scores, key contributing factors, and trends over time.

## Objectives

- Analyze happiness scores across different countries and years.
- Identify key factors associated with happiness.
- Explore the relationship between healthy life expectancy and happiness.
- Examine global happiness trends over time.
- Present findings using clear Excel charts and visualizations.

## Tools Used

- Microsoft Excel
- Data Cleaning
- Pivot Tables
- Excel Formulas
- Data Visualization
- Correlation Analysis

## Key Areas of Analysis

The analysis examines the relationship between happiness and factors such as:

- GDP per capita
- Social support
- Healthy life expectancy
- Freedom
- Generosity

## Visualizations

The Excel dashboard includes charts showing:

- Average happiness score by year
- Healthy life expectancy vs. happiness score
- Correlation between happiness and key factors
- Global happiness trends
